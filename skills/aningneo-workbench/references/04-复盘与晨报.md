# 功能 4：每天复盘与晨报

给它定一个目标（比如一个月涨到多少粉），它就照着这个目标每天复盘：定时看粉丝数，每天早上出一份晨报。

## 1. 目标

`05-选题与排期/目标.md` 写清：

- 起点（日期 + 粉丝数，写清数从哪来）
- 目标（截止日 + 粉丝数）、平均每天要涨多少
- 每周里程碑表：截止、目标粉丝、实际、差多少、这周打法

数字只用真实的：平台抓的或用户说的。目标是用户定的，AI 不自己改；落后了在周报里说清差多少、建议怎么调，用户点头再改。

## 2. 记粉丝数

每次在 `06-复盘/粉丝记录.md` 追加一行：时间、平台、粉丝数、来源（截图 / 接口 / 用户说的）。

| 路线 | 怎么拿 | 频率建议 |
| --- | --- | --- |
| 免费 | 用户每天发一张后台截图，或从创作者后台导出表格放进 `06-复盘/数据/<日期>/` | 一天一次 |
| 付费接口 | 用数据接口查自己账号主页（例：`aningneo-research`） | 你定。频率越高越贵：先算「一天几次 × 单价」，用户同意后写进 `00-总台/授权.md` |

想要「每二十分钟看一次」这种高频，只能走接口，一定先报一天和一个月的总价。

## 3. 每条作品的数据

发布满 **24 小时**、满 **7 天**各记一次，写进 `00-总台/成长/效果账本.md`：

| 编号 | 标题 | 发布日 | 时间点 | 播放 | 点赞 | 收藏 | 评论 | 涨粉 | 和自己中位数比 | 一句结论 |

- 「和自己中位数比」：拿最近 10 条同一时间点的播放算中位数，写 +x% / -x%。**只和自己比**，不和别人比。
- 「一句结论」写猜测时注明「猜」：例「开头 3 秒没出结果，猜是这里掉的」。
- 后台能看到 2 秒跳出、5 秒完播、完播率的，一起记，诊断最有用。

## 4. 晨报

每天 08:30（或用户说「晨报」「今天做什么」时）。复制 `00-总台/模板/晨报.md` 写进 `00-总台/晨报/<今天>.md`。

### 先读

- `05-选题与排期/目标.md`、`06-复盘/粉丝记录.md`、`00-总台/成长/效果账本.md`
- `05-选题与排期/内容总表.md`、`日程表.md`（今天、明天的事；商单节点）
- 每条在做的作品：文稿写好没有、原片到没到、预览出没出
- `03-调研/热点/<今天>/今日热点.md`：明天发什么
- `00-总台/收件箱/` 有没有新东西
- `00-总台/成长/待升级.md` 里「待定」的条数

### 写什么

1. **目标进度**：现在 N 粉，比昨天 +n，离目标还差 N；这周里程碑完成了 x%。在目标.md 的进度表也追加一行。
2. **昨天的数据**：哪条涨了粉、哪条没什么人看（都和自己中位数比，带数）。
3. **下一条怎么改**：3 条，每条写依据（哪条数据、哪条纠正）。会写进下一条在做的作品里。
4. **今天先做这 3 件**：最多 3 件，排序：商单节点 > 有成片没发 > 该复盘 > 卡在用户的（没录、没确认）> 选题补货。每件写一句用户能直接说的话，例：「说『剪 D003』就开始」。
5. **每条内容到哪了**：表格，编号 / 标题 / 到哪了 / 下一步 / 卡在谁。
6. **明天发什么**：从今日热点抄过来，保留还是换、为什么。
7. **要留意的**：该复盘的、收件箱、日程过了时间但用户没说做完的（问一句「做完了吗」）、要先问你的工具、哪些定时任务昨天没跑。
8. **总台在长**：待升级有几条等你点头。

没有的小节写「无」，不硬凑。

### 回复

对话里只回晨报文件路径 + 「今天先做这 3 件」。

## 5. 数据不好时怎么诊断

用户问「这条为什么没流量」或数据明显低于中位数：

| 现象 | 多半是哪里 | 能马上做的 |
| --- | --- | --- |
| 播放少 | 封面标题点不动、前 3 秒留不住、题过气了、发布时间 | 平台允许的话改标题和封面；作者评论补一条 |
| 播放有、赞藏少 | 能拿走的东西不够、不明显 | 评论区补一条「东西在哪拿」 |
| 完播低 | 开头太慢、中间有段没新东西 | 记进下一条的改法 |
| 评论少 | 没有讨论点 | 作者评论抛一个问题，回前几条评论 |

给 3 条下一条的具体改法，写进下一条作品的发布包里。要不要投流只给判断依据，花钱用户定。

## 6. 周报（每周一）

写 `00-总台/周报/<年>-第<周>周.md`（模板 `00-总台/模板/周报.md`）：

- 上周发了什么、每条数据、和再上一周比
- 目标对账：填目标.md 里程碑表的「实际 / 差多少 / 下周打法」
- 什么有效、什么没效（带数据）
- 员工这周派了几件、用上几件（功能 7）
- 下周计划：发几条、每条方向、发布时间。**写成建议**，用户确认后排进日程表并同步日历（功能 5）

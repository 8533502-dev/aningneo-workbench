# 第一次搭工作台

目标：用户照着做完，第二天早上就能看到第一份「今日热点」和「晨报」。

## 1. 开工前问清 6 件事

已经知道的不再问，一次问完，别一条一条挤牙膏。

| 问什么 | 写进哪 | 用来干嘛 |
| --- | --- | --- |
| 账号名、在哪些平台发 | `01-我/我是谁.md` | 刷热点刷哪几个平台；发布文案写几版 |
| 做什么内容、给谁看、不做什么 | `01-我/账号定位.md` | 选题「对口」那一关 |
| 现在多少粉、想多久涨到多少 | `05-选题与排期/目标.md` | 晨报每天对账 |
| 手上有哪些 AI 和工具 | `01-我/我用过的工具.md`、`00-总台/员工/岗位表.md` | 选题「没用过的先问」；分岗 |
| 用哪个 Agent | `00-总台/定时任务.md` | 定时任务怎么设 |
| 工作台放在哪 | — | 初始化的 `--root` |

用户说「先别问，直接搭」就先搭骨架，空着的地方写【待补充】，搭完再补问。

## 2. 建骨架

```bash
# 只预览，不写
python3 <skill目录>/scripts/init_workbench.py --root ~/自媒体工作台 --name "账号名"

# 用户确认后再写
python3 <skill目录>/scripts/init_workbench.py --root ~/自媒体工作台 --name "账号名" --apply

# 用 Claude Code 的再加 --agent claude-code，多建一个 CLAUDE.md（内容只有 @AGENTS.md）
```

- 已有的文件不覆盖，只补缺的。重复跑也安全。
- `<skill目录>` 是这个 Skill 装好后的位置，比如 `.claude/skills/aningneo-workbench/`、`.agents/skills/aningneo-workbench/`。
- 模板会同时复制一份到 `00-总台/模板/`，以后写晨报、发布包都从这里复制。

## 3. 把「我」填进去

- `01-我/我是谁.md`：名字、做什么的、能实测什么、不碰什么、结尾固定说的话（有就填）。
- `01-我/账号定位.md`：内容的几条线（比如「AI 工具教程」「AI 剪辑」），每条线给谁看、看完能拿走什么。
- `01-我/说话卡.md`：贴 3–5 段用户以前的口播原话。**这一步最影响稿子像不像他**，比描述风格管用。
- `05-选题与排期/目标.md`：起点、目标、截止日、每周里程碑（前慢后快也行，用户定）。

## 4. 登记工具和员工

- 用户用过、能实测的工具，每个一行写进 `01-我/我用过的工具.md`。选题时碰到不在表里的工具，先问。
- 用户手上的其他 AI（能联网搜索的、能生图生视频的），按 `references/07-AI员工.md` 分岗写进岗位表。没有其他 AI 也能跑，所有岗位总台自己做。

## 5. 设定时任务

照 `references/定时任务.md`。每个任务设之前说清楚：几点跑、做什么、花不花钱、花多少。用户给的长期授权写进 `00-总台/授权.md`。

## 6. 第一次试跑

按这个顺序当场跑一遍，让用户看到效果：

1. 「今日热点」→ 看 `03-调研/热点/<今天>/今日热点.md`
2. 挑一个题「写稿」→ 看 `04-作品/D001_*/文稿/发布包.md`
3. 「出今天的晨报」→ 看 `00-总台/晨报/<今天>.md`
4. 体检：`python3 <skill目录>/scripts/check_workbench.py --root ~/自媒体工作台`

## 7. 交付时说清楚

- 建了哪些文件（只列目录，不贴全文）
- 明天几点会自动出什么、在哪个文件看
- 现在可以说的 3 句话（例：「今日热点」「这个题帮我写」「出今天的晨报」）
- 哪些地方还是【待补充】，要用户哪天补

# 定时任务怎么设

工作台的「自己跑」靠定时任务。时间都能改，下面是起步建议。

## 任务清单

| 名字 | 什么时候 | 花不花钱 | 提示词（复制进定时任务） |
| --- | --- | --- | --- |
| 今日热点 | 每天 07:30 | 免费路线不花；用付费接口要先授权 | 【定时任务·今日热点】照 aningneo-workbench 功能 1 刷今天的热点、挑题打分，写 03-调研/热点/{今天}/今日热点.md；再照功能 2 锁定明天那条、写好发布包。 |
| 晨报 | 每天 08:30 | 同上 | 【定时任务·晨报】照 aningneo-workbench 功能 4 补到期的数据、记粉丝数，写 00-总台/晨报/{今天}.md。 |
| 记粉丝数 | 你定（一天一次起步） | 看路线 | 【定时任务·记粉丝】照 aningneo-workbench 功能 4「记粉丝数」在 06-复盘/粉丝记录.md 追加一行。 |
| 运营周报 | 每周一 09:00 | 同上 | 【定时任务·运营周报】照 aningneo-workbench 功能 4「周报」写上周周报，下周计划写成建议，排进日程表并同步日历。 |
| 运营学习 | 每周三 21:00 | 只用免费搜索 | 【定时任务·运营学习】照 aningneo-workbench 功能 8 上网学最近的运营方法，存进 03-调研/学习资料/。 |
| 整理建议 | 每周日 21:00 | 不花钱 | 【定时任务·整理建议】照 aningneo-workbench 功能 8 把这周学到的和纠正记录整理成建议，写进 00-总台/成长/待升级.md，不改规则。 |

所有提示词都以「【定时任务·…】」开头。Agent 看到这个开头就知道没人在旁边：**不要问问题**，要用户决定的写进产出文件。

把这张表也抄进工作台的 `00-总台/定时任务.md`，用户改了时间就改那里。

## Claude Code

两种做法，选一种：

**A. 在会话里循环（电脑开着、终端开着才跑）**：在工作台目录打开 `claude`，用自带的定时 / 循环命令（`/loop` 等，以你当前版本的帮助为准）把上面的提示词设成每天几点跑。

**B. 交给系统定时（推荐，关了终端也跑）**：用 `claude -p` 无人值守地跑一次提示词，再交给系统的定时工具。

```bash
# 先手动试一次，能跑通再设定时
cd ~/自媒体工作台 && claude -p "【定时任务·晨报】照 aningneo-workbench 功能 4 ……" \
  --allowedTools "Read,Write,Edit,Glob,Grep,WebSearch,WebFetch,Bash(python3:*)"
```

- macOS / Linux：`crontab -e` 加一行，例：`30 8 * * * cd ~/自媒体工作台 && claude -p "【定时任务·晨报】……" --allowedTools "…" >> 00-总台/定时任务.log 2>&1`。macOS 也可以用 launchd。
- Windows：「任务计划程序」新建任务，操作填同样的命令。
- 无人值守时没人点「允许」，所以要用 `--allowedTools`（或项目 `.claude/settings.json` 的 permissions）把这个任务要用的工具事先放行。**只放行需要的**，别全开。
- 电脑休眠时不会跑。早上跑的任务，前一晚别让电脑睡死，或者在「节能」里设定时唤醒。

## Codex

Codex 的非交互命令是 `codex exec`，同样交给系统定时：

```bash
cd ~/自媒体工作台 && codex exec "【定时任务·晨报】照 aningneo-workbench 功能 4 ……"
```

权限和沙箱按你本机 Codex 的配置来（要能读写工作台目录、能联网搜索）。先手动跑通一次再设 cron / 任务计划。

## WorkBuddy

- 你用的版本如果有「定时任务 / 自动化」功能，直接把上面的提示词填进去，选好时间。
- 没有的话，用手动触发：每天早上打开 WorkBuddy，在工作台里说一句「跑今天的热点和晨报」，效果一样，只是要你自己点一下。

## 跑没跑、跑得对不对

- 每个任务跑完都会在对应文件夹留一个当天的文件（热点、晨报、周报）。没有就是没跑。
- `scripts/check_workbench.py` 会检查晨报和热点是不是超过 2 天没更新。
- 后台任务会因为断网、电脑睡眠、额度用完而整批停掉。晨报里写一句「昨天哪些任务没跑」，断了就补跑，并如实告诉用户。

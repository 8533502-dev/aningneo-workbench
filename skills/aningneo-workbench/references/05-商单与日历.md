# 功能 5：商单排期与日历

一个商单经常有好几期。每一期哪天录、哪天交审、哪天发，它都排进日程，再同步到你的日历。发完之后几天内不能接同类商单（竞品期），它也帮你记着。

## 1. 收进来

- 新建 `05-选题与排期/商单/<YYYY-MM-DD_这单的短名>/`，Brief、品牌资料、对方发来的要求放进 `原始资料/`，原样不改。
- 复制 `00-总台/模板/商单.md` 到这个文件夹，填：
  - 一共几期，每期的主题
  - 每期的节点：脚本交审、录制、成片交审、修改、发布
  - 品牌红线：必须出现的、不能说的、品牌名写法
  - 竞品期：发布后多少天内不接同类（Brief 没写就问用户）
  - 数据要什么时候给、给什么
- 合同、金额、对接人联系方式这些**只放用户本地**，不进任何公开的地方，晨报里也不写金额。

## 2. 排进日程表

`05-选题与排期/日程表.md` 一行一件事：

| 日期 | 开始 | 结束 | 类别 | 事项 | 说明 | 完成 |
| --- | --- | --- | --- | --- | --- | --- |
| 2026-12-03 | 14:00 | 15:00 | 商单 | 某品牌第 1 期：交脚本 | 见商单文件夹 | |
| 2026-12-05 | 10:00 | 11:00 | 录制 | 某品牌第 1 期：录口播 | | |
| 2026-12-08 | 18:00 | 18:30 | 发布 | 某品牌第 1 期 | 发完回前 10 条评论 | |
| 2026-12-08 | 全天 | 2026-12-15 | 竞品期 | 某品牌：不接同类 | 第 1 期发布起 7 天 | |

- 类别只用：发布 / 录制 / 审核 / 商单 / 运营 / 竞品期 / 其他。
- 竞品期这一行「开始」写「全天」，「结束」写结束日期。
- 按用户习惯排时间（例：录制上午、商单下午、发布傍晚），第一次排时问一句。
- 商单的日子，功能 2 不会拿热点去换。

## 3. 新商单进来先查

- 有没有撞上已有的竞品期（同类品牌）→ 撞了就告诉用户，不自己拒。
- 有没有和已有的录制、发布挤在同一天 → 给 2 个挪法让用户选。

## 4. 同步到日历

改了日程表就同步一次，同步完告诉用户加了 / 改了什么。

### 系统日历（苹果日历、Google 日历、Outlook）

```bash
python3 <skill目录>/scripts/schedule_to_ics.py --root <工作台> --out 05-选题与排期/日程.ics
```

- 第一次：把 `日程.ics` 导入日历；或者放进会自动同步的网盘文件夹，在日历里「订阅」这个文件，以后改了自动更新。
- 每件事有固定的编号（按日期 + 开始 + 事项算），重复导入会更新原来那条，不会重复。
- 只建议用一个**专门的日历**（例：「自媒体排期」），别和私人日程混在一起。

### 飞书、钉钉等在线日历（可选）

需要用户自己在对应开放平台建应用、拿到授权，或者装官方命令行工具。接入时：

- 密钥和 token 放环境变量或系统钥匙串，不写进工作台文件。
- 只动专门建的那一个日历，别的日程一条不碰。
- 删除日程也照日程表来：表里删了，日历里删；先列出要删哪几条给用户看。
- 用户在日历里直接拖动的，下次同步会被日程表盖掉——提醒用户要改时间就跟总台说。

## 5. 做没做完

- 「完成」那一列只有用户说「做完了」才打勾。过了时间没打勾的，不当成已完成，晨报里问一句。
- 打了勾的，同步时在日历标题前加「✅」（在线日历支持改标题的话）。

## 6. 发完以后

- 照商单约定的时间记数据（功能 4）。
- 这单什么写法有效、品牌反馈了什么，记进效果账本和纠正记录。
- 品牌红线里新踩的坑，写进商单文件夹的「复盘」一节。

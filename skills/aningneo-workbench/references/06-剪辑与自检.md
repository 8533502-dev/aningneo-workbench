# 功能 6：剪辑与自检

口播录好丢给它，它照着稿子剪。剪完自己先检查一遍（字幕有没有错、声音大不大），有问题自己改掉，再拿给你看。

这里给的是**通用做法**：用 ffmpeg 加几个小脚本就能剪出一条能发的口播片，也可以接剪映或 Remotion。剪辑风格（字体、配色、动效、配乐、片头片尾）每个账号不一样，不在这里，按你自己的写进 `02-方法/剪辑自检表.md` 后面。

## 0. 要装的

- `ffmpeg`、`ffprobe`（必须）
- 语音转字幕：本地免费的 Whisper 类工具（`whisper`、`faster-whisper`、`whisper.cpp` 任选），或付费转写接口（先报价）
- 合成画面（选一个）：剪映（手动拖，导入 SRT）/ Remotion（写代码出片）/ 只用 ffmpeg（最简单）

## 1. 收齐

- 口播原片放进 `04-作品/<编号>/素材/原片/`，录屏、B-roll 放 `素材/录屏/`
- `文稿/发布包.md`：口播稿是**字幕的标准答案**，产品名、人名、术语以稿子为准
- 把稿子里的专有名词抄一份到 `剪辑/<日期-短标题>/专有名词.txt`，一行一个
- 复制 `00-总台/模板/剪辑项目.md` 到 `剪辑/<日期-短标题>/项目.md`，写好：用哪个原片、选定的开头、封面主字、商单红线

## 2. 粗剪：去停顿、去口误

口播原片一般是粗剪前的素材，每次开剪第一步都先精简：

```bash
# 先只看切点（默认不出片）
python3 <skill目录>/scripts/rough_cut.py 素材/原片/口播.mp4 --min-silence 0.6 --keep 0.15

# 看着合适再出片
python3 <skill目录>/scripts/rough_cut.py 素材/原片/口播.mp4 --min-silence 0.6 --keep 0.15 \
  --apply --out 剪辑/<项目>/粗剪.mp4
```

- `--min-silence`：超过多少秒的停顿要切；`--keep`：每个切口两边留多少秒气口，别切得太紧。
- 口误、重说：转写后对照稿子，同一句说了几遍的，只留最后一遍完整的。在剪辑软件里删，或者把要留的时间段写进 `项目.md` 再用 ffmpeg 切。
- 段落之间留一点气口，别全压成一口气。

## 3. 字幕：转写 → 对稿 → 检查

```bash
# 例：用 whisper 出 srt（模型和语言按你装的工具来）
whisper 剪辑/<项目>/粗剪.mp4 --language zh --output_format srt --output_dir 剪辑/<项目>/

# 对着口播稿查字幕
python3 <skill目录>/scripts/subtitle_check.py --srt 剪辑/<项目>/粗剪.srt \
  --script 文稿/发布包.md --terms 剪辑/<项目>/专有名词.txt
```

`subtitle_check.py` 会列出：和稿子对不上的句子（附稿子里最像的那句）、专有名词写错的、太长要拆的行。照着改 srt，改完再跑一遍，直到没有「必须改」。

稿子里没有、但用户临场多说的话，不算错，保留原话。

## 4. 画面

- 照口播稿里的【画面：…】放录屏和 B-roll。录屏前把软件切成浅色模式，字放大。
- 缺画面：派画面员工生成（功能 7），或用免费可商用的素材站，记下来源和授权。
- 第 1 秒放结果画面（成品、操作结果），别用目录或大段文字开场。
- 封面主字 = 首帧大字 = 第一句话说的。

三种合成方式：

| 方式 | 适合 | 怎么做 |
| --- | --- | --- |
| 只用 ffmpeg | 先跑通流程 | `ffmpeg -i 粗剪.mp4 -vf "subtitles=粗剪.srt" -c:a copy 预览.mp4` 把字幕烧进去；B-roll 用 `overlay` 叠 |
| 剪映 | 习惯手动调 | 导入粗剪和 SRT，按【画面】放素材；导出后照样走第 5 步自检 |
| Remotion | 想让 AI 全自动出片 | 把字幕、素材时间点写成 JSON 交给 Remotion 组件渲染；风格组件自己做 |

先出 **720p 预览**，用户点头才出成片。

## 5. 自检（每次出预览、出成片都跑）

```bash
python3 <skill目录>/scripts/check_video.py 剪辑/<项目>/输出/预览v1.mp4 --out 剪辑/<项目>/自检
```

它会量出来并写进 `自检/自检报告.md`：

- 时长、分辨率、帧率
- 响度（目标约 -14 LUFS，峰值不超过 -1 dBTP；平台不同可以改 `--target`）
- 超过 0.8 秒的静音段（多半是没切干净）
- 黑场
- 首帧和第 1、3、5 秒的截图，加每 3 秒一张的总览拼图

然后 AI 自己看截图、对照 `02-方法/剪辑自检表.md` 逐条过：

- 字幕和稿子对得上，专有名词没错，没有错别字
- 字幕和画面上的字不出框、不挡脸、不压在平台按钮的位置
- 声音：人声听得清，配乐比人声低很多，没有忽大忽小
- 第 1 秒是结果画面，前 5 秒说清给谁、得到什么
- 没有超过 8 秒没新东西的段落
- 商单：品牌名写法、必须出现的画面、红线

**注意**：AI 听不到声音，响度和静音是量出来的，画面是看截图判断的。报告里分开写「量出来的」和「看截图判断的」。

## 6. 改了再交

- 报告里每条标「必须改」或「建议」。**必须改的自己改完、重新出预览、重新自检**，不拿去问用户。
- 交给用户：预览文件路径 + 自检报告里「必须改」改了什么、还剩哪些「建议」。
- 用户点头再出成片，放进 `成片/`。用户说哪里不行，记一条纠正（类别「剪辑-…」）。

## 你自己的剪辑风格放哪

字体、配色、字幕样式、动效、配乐、片头片尾，等你剪过几条、知道自己喜欢什么了，写进 `02-方法/剪辑自检表.md` 的「我的风格」一节，自检时一起查。

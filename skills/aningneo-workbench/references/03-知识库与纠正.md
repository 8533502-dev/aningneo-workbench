# 功能 3：知识库与纠正记录

AI 写的稿子一开始会有 AI 味，改了一句，下回还犯。办法是让它记住：你是谁、怎么说话、被你纠正过什么。

## 知识库里放什么

| 文件 | 放什么 | 谁来写 |
| --- | --- | --- |
| `01-我/我是谁.md` | 名字、做什么、能实测什么、不碰什么 | 第一次搭时问，之后用户说了就补 |
| `01-我/账号定位.md` | 内容的几条线、给谁看、看完拿走什么 | 同上 |
| `01-我/说话卡.md` | 常用说法、从来不说的、原话样本、改稿记录 | 原话样本用户贴；其余由纠正记录长出来 |
| `01-我/我用过的工具.md` | 用户认识、用过、能实测的工具 | 用户说「我用过 X」就加 |
| `00-总台/成长/纠正记录.md` | 每一次纠正 | AI 当场写，不用问 |
| `00-总台/成长/效果账本.md` | 每条发出去的数据和一句结论 | 复盘时写 |
| `00-总台/成长/待升级.md` | 要变成固定规则的建议 | 见功能 8 |

## 什么时候记一条纠正

用户做了下面任何一件，**当场**记，不用问：

- 改了稿子、标题、封面字（哪怕只改一个词）
- 说「不对」「太 AI」「不像我」「别这样」「以后都这样」
- 不要某个选题、某个工具、某种剪法
- 挑了几个版本里的某一个（记他挑了什么、为什么）

## 怎么记

在 `00-总台/成长/纠正记录.md` 末尾追加，**只加不改**：

```markdown
## 2026-12-01 | 写稿 | 开头先铺前提

- 场景：写教程类口播稿的第一句
- AI 写的：「XX 装好以后，我们打开设置……」
- 用户要的：「三分钟教你用 XX 做出 YY」
- 以后怎么做：第一句先说观众能得到什么，前提放后面
- 类别：写稿-开头（这类第 2 次）
```

类别用「大类-小类」，同一类用同一个名字，才数得清次数。

## 到第 3 次怎么办

同一个类别记到第 3 次，在 `00-总台/成长/待升级.md` 写一条建议：把它写成固定规则，放进哪个文件（例：`02-方法/写稿手册.md` 开头一节）。用户同意了再改（功能 8）。

## 用起来

- **写稿、选题、剪辑之前**：先在纠正记录里找同场景、同类别的，逐条照做。
- **交稿时**：在回复里说一句「这次照着做了哪几条纠正」。
- **说话卡第「改稿记录」一节**：用户改稿时，按场景记「AI 写的 → 用户怎么说」。攒多了，就能看出他固定怎么换词、怎么接段，整理到说话卡前面几节（也走待升级）。

## 没用过的工具先问

选题、写稿里出现的工具不在 `01-我/我用过的工具.md` 里：

1. 不直接排进日程，不直接写稿。
2. 在今日热点 / 晨报「要先问你的」里列出来：工具名、一句话是什么、为什么值得做。
3. 用户说认识 / 想试 → 加进工具表，照常做；说不要 → 记一条纠正（类别「选题-不认识的工具」），以后同类先问。

## 体检

`scripts/check_workbench.py` 会数纠正记录里每个类别的次数，到 3 次还没进待升级的会提醒。

# 功能 2：写稿（定明天发哪条 + 发布包）

选完题，它自己决定明天发哪一条，再把口播稿、标题、封面字、评论区第一条全写好。用户第二天照着念就行。

## 1. 定明天发哪条

看 `05-选题与排期/日程表.md` 明天的「发布」那一格：

| 那一格写的是 | 怎么做 |
| --- | --- |
| 「已定：…」 | 不动 |
| 商单 | 不动 |
| 「暂定：…」或「热点位」 | 拿暂定题和今天的热点比：暂定题还在上升、仍然最能带播放和粉，就保留；有更好的就换 |
| 空着 | 从今天热点里选分最高、做起来最快的 |

定下来以后：

- 发布那一行改成「已定：<标题>」，同一天的「录制」那一行也改成同一个题。
- 被换掉的暂定题，选题池里状态改成「候选（被 X 月 X 日热点换掉）」，不删。
- 在今日热点和晨报里写一句：明天发什么，为什么换 / 为什么保留。
- 后天以后的只写建议，不锁定。

## 2. 写稿前先读

1. `01-我/我是谁.md`、`01-我/说话卡.md`
2. `00-总台/成长/纠正记录.md`：先看类别「写稿」「标题」的，**同场景的每条都要照做**
3. `00-总台/成长/效果账本.md`：自己什么开头、什么长度数据好
4. `02-方法/写稿手册.md`、`02-方法/钩子库.md`
5. 这个选题在今日热点里的卡（角度、来源）

## 3. 建档

- 草稿用 D 号，发布后改成 C 号（按发布顺序）。文件夹名 `编号_日期_短标题`，例 `04-作品/D003_2026-12-01_某工具三分钟上手/`。
- 里面建 `文稿/`、`素材/原片/`、`素材/录屏/`、`剪辑/`、`成片/`。
- 在 `05-选题与排期/内容总表.md` 加一行，状态「写稿」。

## 4. 写发布包

复制 `00-总台/模板/发布包.md` 到 `文稿/发布包.md`，一次写完：

1. **口播稿**：按段写，每段一个点；需要配画面的地方写【画面：…】。最后放一段「照着念」——只有要念的字，录的时候直接看。
2. **标题**：3 个，标明首选。
3. **封面字**：主字一行（短，一眼看懂结果）+ 副字一行。首帧大字和封面主字一致。
4. **评论区第一条**：作者自己发的第一条评论。有的平台作者评论不能置顶，就发完立刻自己发一条、自己点赞。
5. **发布简介**：写作品本身讲了什么，不复述口播；最后可以抛一个问题引评论。
6. **要准备的**：录屏清单、实测步骤、要用户提前跑的东西。

## 5. 交稿前自检

照 `02-方法/写稿手册.md` 末尾的自检表过一遍。起步版几条：

- 第一句话说出观众能得到什么，不先铺前提
- 讲几个点就先说几个，再一个一个讲
- 每句都是口语，念一遍不拗口
- 没有编的经历和数字（没有的写【待补充】）
- 封面主字、首帧大字、第一句话说的是同一件事
- 同场景的纠正记录都照做了
- 能拿走的东西说清楚在哪拿；不用「关注后私信领」这类交换式说法

## 6. 改稿

- 用户改了哪句，**只改那句**，别借机重写全文。
- 新版直接写进 `发布包.md`，旧版另存 `发布包_v几_旧.md`。不要另起新文件名，不然别的流程找不到。
- 每次改稿都记一条纠正（功能 3）。

## 你自己的写法放哪

- 说话的习惯 → `01-我/说话卡.md`
- 好用的开头 → `02-方法/钩子库.md`
- 自己验证过的爆款规律 → 效果账本里攒够证据后，写进 `02-方法/写稿手册.md`

这三份一开始都是空的，跑一段时间后由纠正记录和效果账本长出来。

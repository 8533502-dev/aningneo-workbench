# 纠正记录

用户每纠正一次，当场在最下面追加一条。**只加不改**。写稿、选题、剪辑之前，先在这里找同场景、同类别的，逐条照做。

同一个类别记到第 3 次，在 `00-总台/成长/待升级.md` 写一条建议，把它变成固定规则。

## 格式

```markdown
## YYYY-MM-DD | 大类 | 一句话标题

- 场景：在做什么的时候
- AI 写的：原样贴
- 用户要的：原样贴用户的话
- 以后怎么做：一句话规则
- 类别：大类-小类（这类第 N 次）
```

大类用这几个：选题 / 写稿 / 标题 / 封面 / 剪辑 / 商单 / 员工 / 其他。小类自己起，同一类用同一个名字。

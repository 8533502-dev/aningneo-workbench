# 定时任务

工作台每天、每周自己跑的事。时间可以改，改了这里也改。怎么在 Claude Code / Codex / WorkBuddy 里设，见 `aningneo-workbench` 的 `references/定时任务.md`。

用的 Agent：【待补充】　　设在哪：【待补充：系统定时 / Agent 自带 / 手动】

| 名字 | 什么时候 | 花不花钱 | 提示词 |
| --- | --- | --- | --- |
| 今日热点 | 每天 07:30 | 免费路线不花；付费接口见授权 | 【定时任务·今日热点】照 aningneo-workbench 功能 1 刷今天的热点、挑题打分，写 03-调研/热点/{今天}/今日热点.md；再照功能 2 锁定明天那条、写好发布包。 |
| 晨报 | 每天 08:30 | 同上 | 【定时任务·晨报】照 aningneo-workbench 功能 4 补到期的数据、记粉丝数，写 00-总台/晨报/{今天}.md。 |
| 记粉丝数 | 【待补充】 | 看路线 | 【定时任务·记粉丝】照 aningneo-workbench 功能 4「记粉丝数」在 06-复盘/粉丝记录.md 追加一行。 |
| 运营周报 | 每周一 09:00 | 同上 | 【定时任务·运营周报】照 aningneo-workbench 功能 4「周报」写上周周报，下周计划写成建议，排进日程表并同步日历。 |
| 运营学习 | 每周三 21:00 | 只用免费搜索 | 【定时任务·运营学习】照 aningneo-workbench 功能 8 上网学最近的运营方法，存进 03-调研/学习资料/。 |
| 整理建议 | 每周日 21:00 | 不花钱 | 【定时任务·整理建议】照 aningneo-workbench 功能 8 把这周学到的和纠正记录整理成建议，写进 00-总台/成长/待升级.md，不改规则。 |

提示词开头是「【定时任务·…】」的就是没人在旁边看着跑的：不要问问题，要用户决定的写进产出文件。

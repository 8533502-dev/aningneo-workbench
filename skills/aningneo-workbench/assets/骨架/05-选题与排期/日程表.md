# 日程表

总台排的每件事都写在这里，改了就同步一次日历（`schedule_to_ics.py` 或你接的在线日历）。要改时间跟总台说，别直接在日历里拖，不然下次同步会被盖掉。

- 时间都是本地时间。类别只用：发布 / 录制 / 审核 / 商单 / 运营 / 竞品期 / 其他
- 自己的内容：只有「已定」的是定死的；「暂定 / 热点位」每天早上按热点重新定明天那条。商单的日子不动
- 竞品期：「开始」写「全天」，「结束」写结束日期
- 「完成」只有用户说做完了才打 ✅

# 作品

一条作品一个文件夹，名字 `编号_日期_短标题`。草稿用 D 号（D001、D002……），发布后按发布顺序改成 C 号。

```text
D001_YYYY-MM-DD_短标题/
  文稿/发布包.md     口播稿、标题、封面字、评论区第一条、简介（模板 00-总台/模板/发布包.md）
  素材/原片/         口播原片
  素材/录屏/         录屏、B-roll、生成的画面（写清来源）
  剪辑/<日期-短标题>/ 项目.md、专有名词.txt、粗剪、字幕、输出/（预览）、自检/
  成片/              用户点头后的成片
```

改稿：新版写进 `发布包.md`，旧版另存 `发布包_v几_旧.md`，不另起新文件名。

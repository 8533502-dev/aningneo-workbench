# 剪辑自检表

每次出预览、出成片都先跑 `check_video.py` 和 `subtitle_check.py`，再照这张表逐条过。每条标「必须改」或「建议」；必须改的自己改完、重新自检，再交给用户。

AI 听不到声音：响度、静音是量出来的，画面是看截图判断的，报告里分开写。

## 字幕

- [ ] 和口播稿对得上（`subtitle_check.py` 没有「必须改」）
- [ ] 专有名词全对，没有错别字
- [ ] 一行不太长，不出框，不压在平台按钮的位置

## 声音

- [ ] 响度约 -14 LUFS，峰值不超过 -1 dBTP
- [ ] 没有超过 0.8 秒的意外静音
- [ ] 配乐比人声低很多，人声听得清
- [ ] 没有忽大忽小

## 画面

- [ ] 第 1 秒是会动、看得懂的结果画面
- [ ] 首帧大字和封面主字一致
- [ ] 前 5 秒说清给谁、得到什么
- [ ] 没有超过 8 秒没新东西的段落
- [ ] 没有意外黑场
- [ ] 字和卡片不挡脸、不出框
- [ ] 录屏看得清，重点有标注

## 商单（有的话）

- [ ] 品牌名写法对
- [ ] 必须出现的画面都有
- [ ] 没碰红线

# 写稿手册（起步版）

写口播稿照这份。起步规则是通用的；你自己的写法，跑一段时间后由纠正记录和效果账本长出来，走待升级加到「我自己的规则」。

## 一、开头

- 第一句话就说观众能得到什么，不先铺前提（「XX 装好以后」这种放后面）。
- 前几秒给出证据：成品、结果、数字（真实的）。
- 要送东西的，开头可以提一句「最后告诉你怎么拿」，中间别反复提。

## 二、中间

- 讲几个点，先说一共几个，再「第一个……」「第二个……」一个一个讲。
- 一段一个点。每段结尾留一个下一段要回答的问题。
- 大约每 15 秒给一个新东西（新画面、新信息、新结果）。
- 讲功能时讲成自己的经历：「我那天……它就……」，别写成说明书。

## 三、能拿走的东西

- 说清是什么、在哪拿。
- 不用「关注后私信领」「评论扣 1」这类交换式说法，各平台规则会变，先查最新的。

## 四、结尾

- 只留一个动作。
- 固定结尾句写在 `01-我/我是谁.md`。

## 五、长度

- 一句话能出结果的，尽量短。
- 教程按步骤数定，别为了凑时长加内容。

## 六、交稿前自检

- [ ] 第一句说出观众能得到什么
- [ ] 封面主字、首帧大字、第一句说的是同一件事
- [ ] 讲几个点先报了数
- [ ] 每句都是口语，念一遍不拗口
- [ ] 对过 `01-我/说话卡.md`
- [ ] 同场景的纠正记录都照做了
- [ ] 没有编的经历和数字（没有的写【待补充】）
- [ ] 能拿走的东西说清在哪拿，没有交换式说法
- [ ] 利他：每段都对观众有用，没有炫技和拖时间的
